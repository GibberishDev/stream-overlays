# Awesome chat combos

## Instalation
1. Download `acc.zip`
2. Extract to desired location on your pc (make sure OBS has read access to that location)
3. In OBS add browser source that covers entire canvas. in source properties select `index.html` from extracted files (toggle local file checkbox **OR** open `index.html` in your browser and copy link from adress bar)
4. In obs when browser source selected click on the "Interact" button
5. That should bring up fading button to change settings on any mouse movement
6. Enter comma separated list of channel names and edit other settings to your hearts content
7. Click save and enjoy
