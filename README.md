# Gibb's Stream Overlays
Custom built browser source overlays I use in streaming. Licensed under MIT so anyone can use and modify them for themselves.
Some overlays require outside OBS plugins or Firebot setup (streamerbot esk program). If thats a case then it will be clearly stated in requirements
